# Draft qualification and recovery — Orange / Green

Mission LFVM-FOUNDATION-AUDIT-001. This phase implements stricter current material-claim evidence coverage, typed claim values, exact source-to-field consistency, freshness limits, contradiction rejection, a bounded canonical OOXML reader with exact sheet/header/table verification, and staged migration pointer recovery. The actual draft workbook is not produced or accepted; every XLSX used in tests is a temporary synthetic OOXML fixture. No public provider data, production keys, or releases are created.

The strict evidence checker verifies internal consistency, not source authenticity or billing truth. It requires an explicit as-of date and current evidence per known material field; E3 minimum, E5 for verified compatibility and E6 for zero-cost verification. Sources with stale review or conflicting current claims cannot qualify. Historical source classifications remain historical. Independent actual source verification is still necessary.

The canonical workbook reader supports a deliberately restricted formula-free, literal OOXML profile with 12 visible worksheets and 11 table parts. ISO date text, strict types and exact headers are required. It rejects formulas, orphan sheet/table parts, hidden rows/columns, merged cells and unexpected table bounds. The synthetic package tests do not establish Excel UI roundtrip, formatting, dynamic expansion, all possible OOXML threats, complete control-table population, or production workbook acceptance.

The staged migration verifier reconciles a 54-record synthetic snapshot, rejects mutation or disappearance of existing canonical rows, and verifies actual staged inventory before atomically replacing a synthetic pointer. The single-writer lock is fail-closed; an abandoned lock needs trusted recovery, not automatic deletion. Failure injection before replacement and stale-pointer tests preserve the old pointer. This is not the real research import and no real version is published.

Design and acceptance constraints remain unchanged: use the existing prebuild gate; production trust roots, independently retrieved source and workbook evidence, a locked blank template, actual workbook tests and owner acceptance are separate. Both teams are roles applied sequentially, not independent agents. Original 45 foundation findings, 28 architecture findings and seven library findings retain their historical records.

Control-table follow-up: exact 149-field dictionary and taxonomy inventory, restored legacy broad/secondary taxonomy, measured manifest table counts and dataset/partition IDs, workbook/worksheet/table content types and unique table identities, and a bounded immutable input snapshot are now checked. The initial reader handles one local workbook; full multi-partition workbook integration, semantic taxonomy definitions, and real Excel compatibility still require actual acceptance. Synthetic control rows are not real library data.
