# LFVM README audit workflow

Audit an owner-selected LFVM ref without changing it. Resolve the ref to a full commit; read its applicable instructions, README, manifests, tests and workflows. Check the first useful action for human readers and agents. Verify links, headings, commands, supported environment and evidence at the selected revision. Record severity, impact, exact source, test status, corrective recommendation and unresolved limits. Separate static inspection from execution.

For a template or research-library branch, preserve the pre-build gate and distinguish the blank template from populated research. Do not claim a workbook exists, a free offer is verified, or a release is accepted without exact evidence. Read [README guide](../README-GUIDE.md), [history](../history/README.md), and [LFVM context](../LFVM-CONTEXT.md). Consult the optional upstream technique catalog at a separately recorded exact commit.

Store future LFVM-only audits here as dated Markdown files. No unrelated upstream portfolio audit has been copied. No homepage change or publication follows automatically from an audit.
