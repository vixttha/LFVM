# LFVM — Spreadsheet Research Library Agent

Permanent branch: `library-of-free-virtual-machines-spreadsheet-library`. This branch owns filled-out spreadsheet editions and their research evidence, not the blank template design. Read [AGENTS.md](AGENTS.md), [WORKFLOW.md](WORKFLOW.md), [LIBRARY-LAWS.md](LIBRARY-LAWS.md) and [TEMPLATE-CONTRACT.md](TEMPLATE-CONTRACT.md).

The [filled version archive](library%20of%20free%20virtual%20machines%20spreadsheet%20version%20filled/README.md) and [version index](library%20of%20free%20virtual%20machines%20spreadsheet%20version%20filled/versions.json) identify the current data checkpoint. **Data v0.0.0.1 is blocked on an accepted blank template.** The prior research baseline contains 54 investigated offers/services, not necessarily 54 providers. No source records or workbook have been imported.

The template agent remains on its own [permanent branch](https://github.com/vixttha/LFVM/tree/library-of-free-virtual-machines-spreadsheet-template). A data revision is independent of its template version; many data editions may use one template. Work offline from accepted schema and public evidence; no mandatory paid compute, accounts, Notion or Sentry. Standard free GitHub public runners only. No main integration without owner approval.
